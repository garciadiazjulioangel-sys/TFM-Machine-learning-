# Predicción del riesgo de enfermedad coronaria mediante Machine Learning

Trabajo Fin de Máster basado en el dataset Framingham Heart Study.

## Objetivo

El objetivo del proyecto es desarrollar y comparar distintos
algoritmos de aprendizaje automático para predecir el riesgo
de enfermedad coronaria a 10 años.

## Modelos evaluados

- Logistic Regression
- Linear Discriminant Analysis
- Support Vector Machine
- K-Nearest Neighbors
- Decision Tree
- Random Forest
- Gradient Boosting
- AdaBoost

También se realizaron técnicas de aprendizaje no supervisado
mediante clustering y reducción de dimensionalidad.

## Metodología

1. Análisis exploratorio de datos
2. Tratamiento de valores ausentes
3. División train/test
4. Tratamiento del desbalance mediante SMOTE
5. Entrenamiento de modelos
6. Evaluación mediante Accuracy, Precision, Recall, F1,
   ROC-AUC y PR-AUC
7. Análisis de clustering
